## Method and limits

* Forks and dataset users come from the Kaggle CLI (read-only). Private forks or private notebooks of other users are not visible and are not counted.
* File reuse: other authors' public notebook outputs were downloaded during the competition and every file (also inside `submission.zip`) was hashed with SHA-256. Only notebooks that are public on 2026-11-15 are listed. Their date is the time their output file was written on Kaggle; for zips with fixed member dates, the zip's own server time.
* The downloads are snapshots (11-14 November 2026); later versions of the same notebooks may use other files.
* Text credits: up to 250 public notebook sources of the competition (sorted by votes and by run date) were pulled with `kaggle kernels pull`; quotes are at most about 12 words. "Last run" is the notebook's latest run time, not the date of the credit.
