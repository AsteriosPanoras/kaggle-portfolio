## Method and limits

* Forks and dataset users come from the Kaggle CLI (read-only). Private forks or private notebooks of other users are not visible and are not counted.
* File reuse (snapshot): other authors' public notebook outputs were downloaded during the competition (11-14 November 2026) and every file (also inside `submission.zip`) was hashed with SHA-256. Their date is the time their output file was written on Kaggle; for zips with fixed member dates, the zip's own server time.
* Version scan (15 November 2026): for every competition notebook of other authors that ran on or after 2026-11-11, every public version was read with the Kaggle API (`kaggle kernels pull OWNER/SLUG/N`, and the output listing of version N): the source, the run log, and up to 12 small text outputs per version (receipts and manifests first; binary files and `submission.zip` were not downloaded). A version's date is the server time of its output files; when a version has no output files, its date is estimated from the neighbouring versions and marked "(estimated)". Kernel inputs listed in Kaggle metadata belong to the latest version only, so per-version inputs are taken from the source (`/kaggle/input/<our slug>`).
* Update scan (evening of 15 November 2026): the same method was repeated incrementally for the notebooks that ran after the first scan (49 notebooks, 188 further versions: 34 notebooks new to the list and those with new versions; the competition notebook list is capped at 500 entries per sort order), with the new hashes `09000960` and `5ea23cc0` and the new slug of our notebook added. Notebooks that Kaggle had renamed (areebbb, maoxin123, arizalfirdaus123) are listed under their current address; the old address redirects. A notebook whose versions have no output files has no version date (shown as unknown).
* Input rows ("used as an input") for notebooks of others come from the Kaggle metadata of their latest version (notebook and dataset inputs); they show attachment, not necessarily that a file was submitted.
* Text credits: quotes are at most about 12 words. For rows from the first pass, "last run" is the notebook's latest run time, not the date of the credit.
