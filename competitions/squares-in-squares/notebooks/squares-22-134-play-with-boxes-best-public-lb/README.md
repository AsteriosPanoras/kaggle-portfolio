# Squares 22.134 | Play with boxes best public lb

Kaggle: [https://www.kaggle.com/code/asteriospanoras/squares-22-134-play-with-boxes-best-public-lb](https://www.kaggle.com/code/asteriospanoras/squares-22-134-play-with-boxes-best-public-lb) · votes: 12 (2026-11-17 midday) · versions: 18 · no medal claimed

Renamed several times (for example "Squares 22.1367 | New Best + 4 Own Improvements", then "Squares 22.135 | Best-of Merge + Own Hop"); the old addresses I checked redirect to the current one (HTTP 302 on 2026-11-17).

The notebook validates and scores a set of packings (a float64 overlap check and the score; the official metric certifies with interval arithmetic) and can write them as `submission.csv`. The packings are the dataset [Squares in Squares - Best Packings](https://www.kaggle.com/datasets/asteriospanoras/squares-in-squares-best): the shortest-per-puzzle merge of the newest public outputs of many authors, listed with credits in the notebook. **My own part is small**: a few puzzles shortened by basin hopping and certified with the competition metric (n=585, 632 and 914; 747, 748, 749 and 804 by a hair).
