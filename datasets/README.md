# Public Kaggle datasets

No data files are stored in this repository; the links go to the datasets on Kaggle.
Download counts are the ones Kaggle reported on 2026-11-15 (`kaggle datasets list --user asteriospanoras`).

| Dataset | What it is | Licence | Downloads | Link |
|---|---|---|---:|---|
| QCC Circuit Atlas | "Every public circuit of Google's quantum compilation contest, with tools": a deduplicated, credited table of the circuit files published in the [Google Verifiable Quantum Circuit Compilation](https://www.kaggle.com/competitions/google-verifiable-quantum-circuit-compilation) competition (1,719 rows: who published each file first and every other source holding the same bytes), readable text versions of the invsqrt and chemistry circuits whose licence allows it, and small pure-numpy tools (simulator, liveness, splicing, chemistry loader check). Created 2026-11-12. | Apache-2.0 | 1,483 | [kaggle.com/datasets/asteriospanoras/qcc-circuit-atlas](https://www.kaggle.com/datasets/asteriospanoras/qcc-circuit-atlas) |
| Supervisory layer for HVAC: SB26 paper code | "Code, protocols and per-episode results of the paper 'Re-select or Learn?'" (see [research/smart-buildings-sb26.md](../research/smart-buildings-sb26.md)) | Apache-2.0 | 41 | [kaggle.com/datasets/asteriospanoras/supervisory-layer-hvac](https://www.kaggle.com/datasets/asteriospanoras/supervisory-layer-hvac) |

Public notebooks of other authors that list a dataset as an input:
`kaggle kernels list --dataset asteriospanoras/qcc-circuit-atlas` (see
[competitions/google-qcc/evidence/USES.md](../competitions/google-qcc/evidence/USES.md)).
